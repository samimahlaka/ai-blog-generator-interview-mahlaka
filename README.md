# AI Blog Generator

A Django-based application that generates SEO-optimized blog posts using OpenAI. Includes daily automation and PostgreSQL support.

## Features

- Generate blog posts from keywords
- Uses OpenAI API for content generation
- Mock or real SEO metrics
- Daily automated post generation
- PostgreSQL for data storage

## Tech Stack

- Python
- Django
- PostgreSQL
- OpenAI API
- python-dotenv (for environment variables)
